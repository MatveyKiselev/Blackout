# Blackout.Core

Платформенно-нейтральная часть: модели, абстракции и вся логика работы. Целевая
платформа — `net10.0`, никаких ссылок на Win32 или UI-тул kits.

```
Abstractions.cs        сервисные интерфейсы + IUiDispatcher
Tray.cs                трей, окно, жизненный цикл, TrayCoordinator
BlackoutController.cs  связка сервисов: настройки, хоткей, простой, оверлей
HotkeySpec.cs          комбинация клавиш и её отображение
MonitorInfo.cs         описание дисплея
AppSettings.cs         модель настроек
JsonSettingsStore.cs   чтение/запись %APPDATA%\Blackout\settings.json
FileLoggerProvider.cs  файловый логгер без внешних зависимостей
```

## Правила

- Никаких `System.Windows.Forms`, `Microsoft.UI`, P/Invoke.
- UI-поток не предполагается: всё, что должно попасть в UI, идёт через `IUiDispatcher`.
- События от платформенных сервисов могут приходить с любого потока — контроллер сам
  маршалит их в UI.
- Сбой записи настроек или лога не должен ронять приложение.

## Что добавлено для второй платформы

Чтобы портировать на macOS, достаточно реализовать интерфейсы из `Abstractions.cs` и
`Tray.cs`: оверлей, хоткей, простой, автозапуск, мониторы, трей, окно. Сам этот проект
менять не нужно.
