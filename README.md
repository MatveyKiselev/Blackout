# Blackout

Утилита для OLED-мониторов: по глобальной комбинации клавиш заливает выбранные экраны
чистым чёрным, `Esc` возвращает рабочий стол. Живёт в системном трее, стартует вместе
с Windows и умеет срабатывать сама, когда пользователя нет за компьютером.

Нативный WinForms-шелл поверх Win32. Без XAML, без MAUI, без .NET-рантайма на машине
пользователя: установщик несёт self-contained сборку.

| Состояние | Working set | Commit | Потоки | CPU в простое |
|---|---|---|---|---|
| В трее, окно не открывали | 5 MB | 13 MB | 20 | 0 |
| Окно открыто | 40 MB | 20 MB | 21 | 0 |

## Возможности

- **Глобальная комбинация** — по умолчанию `Ctrl+Alt+B`, задаётся в настройках.
- **`Esc` снимает оверлей** — регистрируется только пока экран затемнён.
- **Выбор мониторов** — оверлей на каждом выбранном, остальные не трогаются.
- **Автозапуск** — запись в `HKCU\...\Run` с ключом `--background`, стартует без окна.
- **Простой** — если ввода нет N минут, экран гаснет сам; после `Esc` не возвращается,
  пока пользователь не вернётся.
- **Трей** — меню «Настройки», «Чёрный экран», «Выход»; закрытие окна скрывает его.
- **Один экземпляр** — второй запуск открывает настройки уже работающего.

## Требования

- Windows 10 1809 (17763) или новее, x64.
- .NET SDK 10.0 для сборки. Для запуска установленной версии ничего не нужно.

## Сборка и запуск

```powershell
dotnet build Blackout.slnx -c Release
dotnet run --project Blackout.Windows      # окно настроек
dotnet run --project Blackout.Windows -- --background   # только трей
```

Юнит-тестов пока нет; проверка — ручная (см. `Blackout.Windows/README.md`).

## Установщик

```powershell
.\build\package.ps1                  # publish + установщик в artifacts\
.\build\package.ps1 -Version 0.2.0   # версия вручную
.\build\package.ps1 -SkipInstaller   # только publish
```

Требуется [Inno Setup 6](https://jrsoftware.org/isdl.php) (`winget install JRSoftware.InnoSetup`).
Результат: `artifacts\Blackout-<version>-setup.exe`, per-user установка без прав администратора.

## Как это устроено

Логика не знает про платформу. `Blackout.Core` содержит контроллер и интерфейсы, каждая
платформа реализует их по-своему.

| Интерфейс | Назначение |
|---|---|
| `IHotkeyService` | одна глобальная комбинация, событие нажатия |
| `IOverlayService` | показать чёрное на списке мониторов, событие «снять» |
| `IMonitorService` | перечисление дисплеев со стабильными id |
| `IIdleMonitor` | время простоя и событие порога |
| `IAutostartService` | запись в автозапуск ОС |
| `ISettingsStore` | JSON-настройки |
| `ITrayService` | иконка и меню |
| `IAppWindowService` | показать/скрыть окно |
| `IAppLifetime` | завершить приложение |
| `IUiDispatcher` | маршалинг в UI-поток |
| `ISingleInstanceGuard` | один экземпляр на сессию |

`BlackoutController` связывает всё: применяет настройки, регистрирует хоткей, слушает
простой, показывает оверлей. Windows-слой (`Blackout.Windows`) даёт реализации.

### Потоки

UI-поток WinForms не используется для нативных окон. Оверлей, хоткеи и IPC живут на
отдельных pump-потоках с собственным `GetMessage`-циклом (`Interop/MessagePumpThread`),
стек 256 KB. Оверлей висит на `WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`,
не активируется, не попадает в Alt+Tab, скрывает курсор и игнорирует `Alt+F4`.

`Esc` регистрируется **до** затемнения: если его перехватить нельзя, экран не гаснет.

### Простой

Таймер не опрашивает систему раз в секунду. Он взводится на точное время до порога
(с потолком 30 минут), поэтому таймаут в 10 минут — это ~1 пробуждение вместо 600.

## Настройки и данные

- `%APPDATA%\Blackout\settings.json` — комбинация, мониторы, автозапуск, таймер.
- `%APPDATA%\Blackout\blackout.log` — журнал (ротация на 2 MB).
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Blackout` — автозапуск.

Мониторы хранятся по стабильному id (`\\?\DISPLAY#...#{GUID}`). Если кабель переехал в
другой порт, id меняется — тогда используется основной монитор, и об этом пишется в
статусе.

## Ограничения

- Эксклюзивный fullscreen (игры, DRM-видео) оверлей не перекрывает.
- Хоткей не срабатывает, когда фокус в приложении с повышенными правами (UIPI).
- Комбинации с `Win` не поддерживаются: ОС перехватывает их раньше приложения.
- Без подписи кода SmartScreen показывает предупреждение о неизвестном издателе.
- Один экземпляр — на сессию пользователя.

## Дорожная карта

1. Подпись кода (OV/EV или Azure Trusted Signing) для exe и установщика.
2. Версия приложения в окне настроек.
3. macOS: `Blackout.Mac` на AppKit (`NSStatusItem`, `NSWindow` с `level = .screenSaver`,
   `RegisterEventHotKey`, `SMAppService`). `Blackout.Core` переиспользуется целиком.
4. Юнит-тесты на `HotkeySpec` и выбор мониторов.
